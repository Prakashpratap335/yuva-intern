# Week 5 – Predictive Modeling and Algorithm Selection

## Project: Beauty and Wellness Customer Behaviour Analysis

### Overview
This week focuses on Predictive Modeling and Algorithm Selection using the Sephora Products and Skincare Reviews dataset from Kaggle.

The main objective is to develop a predictive modeling strategy to understand customer satisfaction, analyse product reviews, and support better beauty product discovery.

### Tasks Covered

1. **Regression Analysis:** Predict numerical product review ratings using Linear Regression, Decision Tree Regressor, and Random Forest Regressor.

2. **Classification:** Identify potentially low-rated customer reviews using Logistic Regression, Decision Tree Classifier, and Random Forest Classifier.

3. **Clustering:** Explore similar product groups using K-Means and Hierarchical Clustering.

4. **Model Evaluation:** Study MAE, RMSE, R², Precision, Recall, F1-score, ROC-AUC, and Confusion Matrix.

5. **Model Validation:** Understand train-test splitting, cross-validation, overfitting, underfitting, and data leakage prevention.
